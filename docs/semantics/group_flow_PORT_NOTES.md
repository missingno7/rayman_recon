# Game flow and UI contracts

These contracts describe DOS GOG v1.21. Exact addresses, readers/writers, confidence levels and remaining questions are in the fourteen proposed registries. All numeric file fields are little-endian; file records are independent of native pointer sizes.

| Unit | Contract the port must retain |
|---|---|
| menu | Stages 0/3/4/7/8/9/10 select general/save/options/keys/pad/graphics/video. Preserve release/repeat/fade gating and callback order. `options_t` is an overlapping working view, including seven key words and three one-hot video choices. Physical button detection differs from pad action remapping. Frequency selectors 0/1/2 differ from literal 70/80/100 Hz. |
| worldmap | Twenty-four nodes; self-neighbor means no movement. Runtime access masks are 0x01 accessible, 0x02 traversal/neighbor scratch, 0x04 pending unlock. Paths reach 128 before unlocking; 102 cages enables node 17. Save nodes are 18..23. Retain map-specific type-54/main-5 medallion states and continue/loader command phases. All 50 shipped non-self edges have both coordinate deltas nonzero. |
| cheat | Nine-byte newest-first XOR-0x96 scan history; consume pending flag before eligibility checks. Layout-specific fixed prefix lengths and first-matching cheat priority matter. Preserve special-world/squashed/fist/stationary gates, clamping, frequency restoration, and the observed node-14 unlock exception. Loading/cleanup and timer-palette routines also reside in this unit. |
| save | Decoded slot is exactly 2,682 (`0xA7A`) bytes. Progress event bits are MSB first, 32 bytes per level. Runtime access flags are repacked to save bits 0/1 plus three cage bits. Two-byte `world_index` I/O also touches adjacent `ALL_WORLD`; keep the true one-byte declaration. `LoadInfoGame` changes shared gameplay globals. CFG is 132 bytes; preserve low-byte writes and API success polarity. |
| savecodec | Five-byte obfuscated checksum/length header, 256 rows of eight-byte differential dictionary, lowest-row match ties, LSB-first change mask, delayed decode output and short-final-block marker. Rolling key starts 0x57 and wraps as a byte; payload checksum uses decoded bytes. Normal stream termination and reported error are separate flags. |
| cdsave | DOS vectors are six-byte far pointers. Preserve the documented CD readiness/limited-state transitions. The save-availability probe is independent of the actual save directory: original offsets overwrite the slash, and DOS name truncation can make the generated probe writable. Existing port policy is in `docs/port/PLATFORM_OPEN.md`, section 6. |
| input | Key states are 0/0x80; `TOUCHE` returns the raw byte. Opposite keyboard directions cancel; replay overrides directions. Keep E1/1D/45 pause recognition, fade-gated buttons, calibrated joystick thresholds and callback selection. Replay bits 4 and 8 both set A2; B2 stays zero. Replay consists of input/repeat pairs; this unit does not encode recording data. |
| jumelle | Separate world camera, integer screen lens, and signed coordinates with four fractional bits. Radius 25..64; width 7r/2, height 2r; x projection includes +8. Preserve narrowing, unsigned amplitude comparisons, 224-stride displacement lookup, and 320-byte pixel stride. Idle auto zoom begins at 1800 update calls, radius target at 1830; movement/input cancels it. |
| box | Packed-byte plasma arithmetic wraps at 256 and coordinates at 128. Fire updates its grid in place, with distinct edge formulas. Preserve palette channel permutations, next-boundary alignment, and historical clipping formulas in their observed input domain. `CalcTab` retains the known one-byte double-constant NEAR residue. |
| pcmain | Keep menu/world/level/death loop boundaries, signed lives, transitions and draw order. One displayed frame can simulate `display_mode+1` ticks plus deadline catch-up. Catch-up increments a non--1 iframe timer; idle pause threshold is 21,600 loop iterations. ModeX background reload policy differs from Normal mode. Startup debug-watch omission is an existing port decision, not new behavior evidence. |
| ray_pc | Logo resource 29, temporary arena 0x2EE00, paired palette/buffer metadata swaps. Countdown -1 skips a phase; only the second logo wait accepts input. |
| sysutils | Arena cursor resets and sprite checkpoints do not relocate payloads. Historical adjustment is `size += size & 3`. Temporary pool has 30 descriptors and heap fallback; descriptor availability is not guaranteed. Preserve caller-visible lifetime/ownership. Existing malloc-wrapper policy is in `docs/port/PLATFORM_OPEN.md`, section 8. |
| mathutil | Trigonometry: 512 angle units per turn, amplitude 512, signed folding and narrowing. Two-bit slots are MSB indexed; byte-array bit helpers are LSB first. Bit predicates return masks rather than normalized one. |
| rand | Preincrement table index; first sample after reset is slot 1. Refill all 256 entries even without reseeding. Return table value modulo `max+1`, including the upper bound for valid nonnegative inputs; do not introduce the PS1 accumulator. |

Detailed byte offsets for SAV/CFG, the pinned map graph, and rejected hypotheses are retained in `evidence/save_formats.json`, `evidence/world_graph.json`, and `evidence/negative_results.json`. Unresolved intended meanings remain in `UNCERTAIN.md`; they introduce no new names.

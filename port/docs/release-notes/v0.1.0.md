The first release of the native port of DOS **Rayman** (PC version 1.21, the version GOG sells in "Rayman Forever"),
rebuilt from this project's reconstruction of the original program's source code. It plays your own copy of the game;
no game files are included.

## Download

| Platform | Package | Install |
|---|---|---|
| Windows (64-bit) | `rayman_sdl3-0.1.0-windows-x64.zip` | copy `rayman_sdl3.exe` and `SDL3.dll` into the game folder - in GOG's Rayman Forever the `Rayman` folder - and start `rayman_sdl3.exe` |
| Linux (64-bit, glibc 2.35+) | `rayman_sdl3-0.1.0-linux-x64.tar.gz` | copy `rayman_sdl3` and `libSDL3.so.0` into the game folder and start `./rayman_sdl3` |
| Android 7+ (arm64, x86_64) | `rayman_sdl3-0.1.0-android.apk` | install; on the first start pick your game folder (copy GOG's "Rayman Forever" folder to the phone first) |

The `-symbols` archives hold debug information for crash reports only.

## What you get

- The original game, reconstructed: the game logic is the v1.21 program's, checked byte for byte against GOG's
  `RAYMAN.EXE` by the project's matching toolchain.
- Works in a GOG install out of the box: GOG's CD (`game.ins`, `game.gog`) and its Ogg music, saves in GOG's
  `cloud_saves` (shared with GOG's own launcher). An original Rayman CD - an image next to the game or a disc in a
  drive - is preferred for the music when present.
- Widescreen up to the window's shape (default), 16:9, 21:9 or the original 320 columns; square or original 4:3
  pixels; fullscreen - all in the game's Options > Graphics Details > Video mode, changeable while playing.
- Plays without any CD (without music), unlike the original's limited mode.
- Android: touch controls that follow the official Android release, gamepad support, first-start folder picker.
- Gamepads on every platform.

## Known limitations

- Only Rayman PC version 1.21 (GOG) is supported; other versions (for example the v1.12 CD release) show a message
  instead of starting.
- GOG's music files cut three tracks short (the Jungle, Picture City and Caves of Skops themes play for about a minute,
  then silence until the game restarts them; the Jungle theme is also a different piece) - as in GOG's own release. An
  original Rayman CD has the full tracks and is preferred when present.
- GOG's release has no intro or ending movie; they play when `INTRO.DAT` / `CONCLU.DAT` from an original CD install
  are in the game folder, or from an inserted original CD.
- Boss fights, level endings, timed levels and the victory sequence are not covered by the automated tests yet.
- Android: the touch controls also show during the attract-mode demos; a corrupted edge was seen once around the
  firefly light in a dark level and is not explained yet.

Problems: please attach `rayman_log.txt` (written in the game folder; on Android in the app's folder) to an issue.
